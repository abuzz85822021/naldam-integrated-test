날담 + 나의 아바타 통합 테스트 v1

[적용]
기존 운영 사이트를 보존하려면 별도의 GitHub 저장소에 이 ZIP 내부 파일들을 업로드하세요. ZIP 파일 자체를 올리는 것이 아니라 압축을 풀어 내부 파일을 업로드합니다.

[구현]
- 날담 상단에 오늘의 날담 / 나의 아바타 전환 메뉴
- 기존 날담 카카오 로그인, 메모, 역사/명언/달력 코드 유지
- 기존 나의 아바타 v0.9 기능을 avatar.html로 그대로 포함
- PWA 서비스 워커에 avatar.html 캐시 추가

[중요: 아직 미구현]
- 나의 아바타는 기존 코드대로 브라우저 localStorage에 저장됩니다. Supabase 사용자 계정과 연동되지 않습니다.
- 날담 달력과 아바타 기록은 아직 하나의 달력으로 합쳐지지 않았습니다.
- 로그인/기록 통합은 다음 단계에서 Supabase 테이블과 RLS 정책을 설계하고 연결해야 합니다.
- 아바타 3D 모듈은 인터넷 연결이 필요할 수 있습니다.
